# Генерация синтетических данных

## Источники и мотивация

Основной датасет посещаемости является синтетическим, потому что открытых ежедневных данных о посещаемости столовых ВШЭ нет. Примерную логику обсудил с Сергеем Николаевичем, поэтому она должна быть схожа с реальной. При этом генерация опирается на реальные признаки:

- календарные даты за два года;
- погодные данные из Open-Meteo Historical Forecast API;
- список реальных корпусов ВШЭ в Москве;
- учебную структуру ВШЭ: 4 модуля и периоды сессий/проектных сессий.

Погодный CSV был скачан по запросу:

```text
https://historical-forecast-api.open-meteo.com/v1/forecast?latitude=55.7558&longitude=37.6176&start_date=2024-04-25&end_date=2026-04-25&daily=temperature_2m_mean,relative_humidity_2m_mean,precipitation_sum&timezone=Europe%2FMoscow&format=csv
```

Параметры выгрузки:

- координаты: Москва, `55.7558`, `37.6176`;
- период: `2024-04-25` - `2026-04-25`;
- дневные признаки: `temperature_2m_mean`, `relative_humidity_2m_mean`, `precipitation_sum`;
- часовой пояс: `Europe/Moscow`;
- формат: CSV.

В генерации используются температура, влажность и сумма осадков за день.

Каждая строка датасета соответствует одной дате и одному корпусу:

```text
1 строка = 1 день + 1 корпус ВШЭ
```

## Формула посещаемости

Для каждого корпуса используется интерпретируемая аддитивная формула:

```text
visitors_count =
    base_flow
  + weekday_effect
  + class_weight * avg_classes_today
  + morning_weight * avg_classes_morning
  + evening_weight * avg_classes_evening
  + session_weight * session_progress
  + project_session_effect * is_project_session
  + temperature_effect
  + precipitation_effect
  + random_noise
```

После этого применяются понижающие коэффициенты для выходных и летних месяцев.

## Почему формула такая

- Больше пар в день увеличивает количество людей в корпусе и спрос на столовую.
- Утренние пары сильнее повышают обеденный поток.
- Вечерние пары влияют слабее или отрицательно, потому что часть студентов уходит после дневных занятий.
- Ближе к сессии поток немного растёт из-за консультаций, дедлайнов и подготовки.
- Проектная сессия меняет обычный учебный ритм, но всё равно может давать дополнительный поток.
- Сильные осадки могут снижать посещаемость в отдельных корпусах: часть людей не приезжает или выбирает доставку/еду рядом.
- Для крупных комплексов вроде Покровки базовый поток выше, для малых корпусов ниже.

## Запуск

```bash
python -m src.data_generation
```

Результат сохраняется в:

```text
data/raw/canteen_visitors_synthetic.csv
```

При необходимости можно изменить модификаторы корпусов в `data/raw/buildings.csv` и заново запустить генерацию.
